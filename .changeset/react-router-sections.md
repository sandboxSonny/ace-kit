The React Router starter made by `ace-kit create` now has the hero, FAQ and gallery sections, like the Astro one, and its published date and button. `ace-kit sync`, `ace-kit doctor` and the dev server look for `*.schema.ts` files in `app/` as well as `src/`. The docs now say a React Router site needs an `index` route as well as the `*` route, because `*` doesn't match `/`.
